Chat

← Volver al Índice
Sistema de mensajería en tiempo real estilo WhatsApp. Canales públicos (General, Rodadas, Mecánica, Directiva) y grupos privados con stickers, notas de voz, dictado por voz y reacciones.

Composables (UI)

ClubChatScreen

Pantalla principal del chat. Selector de canales (4 built-in + grupos privados), lista de mensajes con auto-scroll, UI de grabación de audio, picker de stickers, reply/citar, eliminación de mensajes, reacciones, y gestión de grupos.

ChatMessageBubble

Burbuja de mensaje con reacciones, contexto de reply, reproducción de audio, y visualización de stickers.

ViewModel Methods

onSendMessage

Enviar mensaje de texto a un canal con soporte para reply.

onDeleteMessage

Eliminar mensaje (para todos).

onDeleteMessageForMe

Eliminar mensaje (solo para mí).

onMarkMessageAsRead

Marcar mensaje como leído.

onSendSticker

Enviar sticker a un canal.

onSendAudio

Enviar nota de voz con duración y transcripción.

onToggleReaction

Agregar/quitar reacción emoji a un mensaje.

onCreatePrivateGroup

Crear grupo privado con miembros seleccionados.

onAddMembersToGroup

Agregar miembros a un grupo privado.

onLeaveGroup

Salir de un grupo privado.

onDeleteGroup

Eliminar grupo privado (solo admin/creador).

Modelos de Datos

ChatMessage

id, channelId, senderMemberId, senderName, messageText, timestamp, messageType, readBy, replyToMessageId, reactions, audioDurationSeconds, deletedForMemberIds

MessageType

TEXT, STICKER, IMAGE, AUDIO, LOCATION

ChatChannel

GENERAL, RODADAS, MECANICA_AUXILIO, DIRECTIVA

PrivateGroup

id, name, description, creatorMemberId, memberIds, adminIds, isBlockedByDirectiva

Consejos

  • El canal DIRECTIVA es solo para miembros de directiva
  • Se pueden enviar notas de voz con grabación integrada
  • El dictado por voz transcribe audio a texto automáticamente
  • Los stickers se gestionan desde GESTOR_STICKERS.kt
  • Los mensajes eliminados se marcan comoDeletedForMemberIds
  • El chat funciona offline con cola de mensajes pendientes
