OTA / Notificaciones

← Volver al Índice
Actualizaciones OTA (Over-The-Air) desde GitHub y Firestore, notificaciones FCM push, y sistema de notificaciones in-app con bandeja de entrada.

Archivos del Módulo

  • ACTUALIZADOR.kt
  • NOTIFICACIONES.kt
  • VISTA_INFO.kt
  • NOTIFICACIONES_APP.kt
  • ui/screens/VISTA_NOTIFICACIONES.kt
  • SERVICIO_MENSAJERIA.kt

Composables (UI)

VerificadorOta

Se ejecuta automáticamente al iniciar la app. Verifica actualizaciones y muestra diálogo de confirmación y progreso de descarga.

DialogoProgresoDescargaOta

Diálogo de progreso de descarga con barra de progreso en tiempo real, manejo de errores y fallback al navegador.

VistaInfoScreen

Pantalla de información/about con versión actual, botón de verificación manual y diálogo de donaciones.

SolicitadorNotificaciones

Solicita permiso POST_NOTIFICATIONS (Android 13+) y suscribe a temas FCM.

VistaNotificaciones

Bandeja de entrada de notificaciones in-app con badge de no leídas, marcar como leído y items clickeables.

ViewModel Methods

Este módulo no usa ViewModel directamente.

Modelos de Datos

InformacionOta

versionCode, urlDescarga, notas

NotificacionApp

id, tipo, titulo, mensaje, referenciaId, canalOrigen, leida, timestamp, icono

Sincronización en la Nube

  • Firestore (configuracion/OTA)
  • GitHub CDN fallback
  • FirebaseMessagingService

Consejos

  • OTA busca primero en Firestore, luego en GitHub releases
  • La descarga maneja redirecciones HTTP automáticamente
  • Las notificaciones FCM usan tópicos (global, alertas_sos)
  • Las notificaciones in-app se almacenan en Room DB
  • Se limpian automáticamente notificaciones mayores a 30 días
