Directiva

← Volver al Índice
Panel exclusivo de gobernanza. Generación de códigos de invitación, gestión de solicitudes, administración de roles, chat directiva y grupos privados.

Composables (UI)

DirectivaExclusiveScreen

Panel principal con acceso verificado, tabs de navegación, y controles (modo directiva, killswitch chat, limpiar chat).

DirectivaCodigosSection

Lista de códigos de invitación generados.

DirectivaSolicitudesSection

Solicitudes de acceso pendientes.

DirectivaCargosSection

Gestión de roles y miembros.

DirectivaPrivateGroupsSection

Administración de grupos privados.

ViewModel Methods

onGenerateCode

Generar código de invitación (estándar o especial) con duración configurable.

onDeleteCode

Eliminar código de invitación.

onApproveRequest

Aprobar solicitud de acceso y generar código.

onRejectRequest

Rechazar solicitud de acceso.

onTransferCargo

Transferir cargo de un miembro a otro.

onAssignRole

Asignar rol a un miembro.

onClearGeneralChat

Limpiar todos los mensajes del chat general.

onUnlockWithMasterCode

Desbloquear acceso con código maestro.

onToggleDirectiva

Activar/desactivar modo directiva.

onToggleChatEnabled

Habilitar/deshabilitar chat (killswitch).

Modelos de Datos

InvitationCode

id, code, isMaster, isSpecialGuest, durationHours, expiresAt, isUsed, targetRole

AccessRequest

id, fullName, phone, requestType, reasonMessage, status, generatedCode

RoleConfig

roleKey, customTitle, roleDuties, badgeIconName

Sincronización en la Nube

  • InvitationCodeSync.kt
  • InvitationCodeCleanupJob.kt
  • AccessRequestSync.kt
  • RoleConfigSync.kt

Consejos

  • Acceso restringido solo a miembros con rol de directiva
  • Códigos de invitación tienen expiración configurable (6-48h)
  • El código maestro desbloquea acceso sin invitación
  • El killswitch de chat puede desactivar el chat para todos
  • La limpieza de chat es irreversible
